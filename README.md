# cbefs-model-bgc-repo

The Chesapeake Bay Environmental Forecast System's biogeochemistry, as gridded
data for the oceansensing.org ocean map: dissolved oxygen, pH, total
alkalinity and aragonite saturation state at the surface, the bottom and fixed
depths, and nitrate, ammonium and phosphate at fixed depths, as daily means
from a day behind to two days ahead.

Updated four times a day.
